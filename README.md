# De Excel a agentes

Propuesta de curso de tecnología agéntica para periodistas: cada participante termina con un proyecto propio de datos, hecho con un agente de IA y publicado en una página web.

**Sitio:** https://jmtoral.github.io/propuesta_curso_agentes/

- `docs/index.html`: el curso, conceptos, costos y temario
- `docs/instalacion.html`: manual de instalación para Windows y Mac
- `docs/sesiones/`: presentaciones en HTML, una por sesión (se avanza con ↓, Espacio o scroll)
- `docs/img/`: diagramas en SVG
