El entorno de trabajo

VS Code, Git y GitHub: la red de seguridad.

El problema

El agente se va a equivocar. La pregunta es si pueden deshacerlo.

El flujo
Vocabulario

Git en cinco palabras

RepositorioUna carpeta con memoria de cada versión.
CommitGuardar una versión con una nota de qué cambió.
PushSubir esas versiones a GitHub.
GitHubLa copia en la nube. También publica páginas web.
RevertirVolver a una versión anterior.
VS Code

Un solo lugar para todo

  • Explorador: los archivos de la carpeta, a la izquierda.
  • Editor: abren cualquier archivo y ven qué escribió el agente.
  • Terminal integrada: donde corre claude. Menú Terminal → Nueva terminal.
  • Control de código fuente: el ícono de ramas. Muestra qué cambió desde el último commit, línea por línea.
Práctica · 25 min

Su primer repositorio

  1. Creen una carpeta mananeras y ábranla en VS Code (Archivo → Abrir carpeta).
  2. En la terminal, abran claude y pídanle: «inicializa un repositorio de Git aquí y haz el primer commit».
  3. En Control de código fuente, den clic en Publish to GitHub y elijan repositorio privado.
Práctica · 20 min

Ahora, rómpanlo

  1. Pídanle al agente que borre o cambie un archivo.
  2. Vean en Control de código fuente qué cambió exactamente.
  3. Deshagan el cambio: descarten los cambios en VS Code, o pídanle a Claude «regresa todo al último commit».

Claude Code también guarda puntos de control propios: Esc dos veces para volver atrás en la conversación.

Regla

Commit antes de cada encargo grande.

Si algo sale mal, siempre hay a dónde regresar.
