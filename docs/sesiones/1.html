Chat vs. agente

Qué cambia cuando la IA puede tocar tus archivos.

La pregunta de hoy

Ya usan ChatGPT o Claude. ¿Para qué otra cosa?

La diferencia
Vocabulario

Cuatro palabras

ModeloEl que piensa y escribe. Aquí, Claude.
HarnessEl programa que le da manos al modelo. Aquí, Claude Code.
HerramientasLeer y escribir archivos, correr programas, buscar en la web.
ContextoTodo lo que el modelo tiene a la vista en este momento. Tiene límite y se llena.
La fórmula

Agente = Modelo + Harness

El modelo es el mismo para todos. El harness es lo que ustedes diseñan.

Cómo llegamos aquí
2022–2024

Prompt engineering

La era de las «fórmulas mágicas»: «actúa como experto», «piensa paso a paso», ejemplos en el mensaje.

Sirvió, pero tenía un techo: el modelo solo sabía lo que cupiera en ese mensaje, y la respuesta acababa en un copiar y pegar.

2025

Context engineering

Tobi Lütke (Shopify) y Andrej Karpathy popularizan la idea: lo que importa no es la frase, sino todo lo que el modelo tiene a la vista.

  • Documentos, historial, resultados de herramientas, memoria.
  • El contexto es finito: si se llena de ruido, el modelo empeora.
  • El trabajo pasa a ser decidir qué entra y qué se queda fuera.
2026

Harness engineering

Mitchell Hashimoto lo describe así: cuando el agente comete un error, no reescribes el prompt. Arreglas el entorno para que ese error no vuelva a ocurrir.

Herramientas, permisos, reglas, controles automáticos, una forma de deshacer. El modelo es una pieza; el sistema es el producto.

Costos · 1

Todo se cobra en tokens

  • Un token es un pedazo de texto de unas pocas letras.
  • Se paga lo que el modelo lee (entrada) y lo que escribe (salida). Escribir cuesta 5 veces más.
  • Plan: Claude Pro, 20 dólares al mes, con límites de uso que se reinician. Es lo que usamos.
  • API: pago por token, para programas que procesan miles de documentos solos.

Costos · 3

Por qué un agente gasta más

En cada vuelta del bucle, el agente vuelve a leer toda la conversación. Una hora de trabajo puede mover millones de tokens.

  • /clear entre tareas distintas.
  • Subagentes para lo que lee mucho.
  • El modelo barato para lo repetitivo.
Quién manda

El agente pide permiso

  • Antes de editar un archivo o correr un comando, Claude Code pregunta. Ustedes aprueban o rechazan.
  • Con Shift + Tab cambian de modo: pedir permiso en todo, aceptar ediciones o modo plan (solo propone, no toca nada).
  • Siempre lo abren dentro de la carpeta del proyecto, nunca en todo el disco.
Práctica · 30 min

El mismo encargo, dos veces

Tienen una carpeta con 3 versiones estenográficas de mañaneras. El encargo: ¿cuántas preguntas hizo la prensa en cada conferencia?

En el chatCopien y peguen el texto de cada conferencia.
En Claude CodeAbran la terminal en la carpeta, escriban claude y pídanlo.
Comparen

Tres preguntas

  1. ¿Quién movió los archivos?
  2. ¿Pueden repetirlo mañana con 30 conferencias más?
  3. ¿Pueden revisar cómo llegó al número?

El agente deja un programa que pueden volver a correr y revisar. El chat solo deja una respuesta.

Datos sensibles

Qué sale de su máquina

  • Todo lo que el agente lee viaja a los servidores de Anthropic para procesarse. Eso incluye los archivos que abre, no solo lo que ustedes escriben.
  • En claude.ai → Configuración → Privacidad deciden si sus conversaciones se usan para mejorar los modelos. Revísenlo hoy.
  • Lo que no está en la carpeta, el agente no lo ve. Por eso cada proyecto vive en su propia carpeta.
Cuándo no

FuentesNombres, contactos o mensajes de fuentes protegidas.
FiltracionesDocumentos que no son públicos.
Datos personalesDe personas que no son figuras públicas.

Regla del curso: solo datos públicos, en las prácticas y en el proyecto final.
