Instalación

Antes de la sesión 1 hay que tener cuatro programas funcionando: Git, Python, VS Code y Claude Code. Toma unos 30 minutos.

Antes de empezar

  • Una cuenta de Claude Pro en claude.ai. Con la versión gratuita no funciona Claude Code.
  • Una cuenta gratuita de GitHub en github.com. Usen un correo que revisen.
  • Permiso para instalar programas. Si es una laptop de su medio y pide una contraseña de administrador que no tienen, avisen antes de la sesión 1.

No necesitan saber usar la terminal. Copien y peguen los comandos con el botón «Copiar», no los escriban a mano.

Tengo Windows → Tengo Mac →

Windows

Requiere Windows 10 o posterior. Instalen en este orden.

  1. Git. Descarguen Git for Windows desde git-scm.com/downloads/win e instálenlo. Acepten todas las opciones que vienen por defecto.
  2. Python. Descarguen la versión más reciente desde python.org/downloads. En la primera pantalla del instalador, marquen la casilla «Add python.exe to PATH» antes de dar clic en Install.
  3. VS Code. Descárguenlo desde code.visualstudio.com e instálenlo con las opciones por defecto.
  4. Claude Code. Abran el menú Inicio, escriban PowerShell y ábranlo. Copien este comando, péguenlo y presionen Enter: 
    irm https://claude.ai/install.ps1 | iex
    No muestra avance mientras descarga; esperen a que vuelva a aparecer PS C:\Users\...>. No hace falta abrirlo como administrador.
  5. Inicien sesión. Cierren PowerShell, abran uno nuevo, escriban claude y presionen Enter. Se abre el navegador: entren con su cuenta de Claude Pro y autoricen. Para salir de Claude Code, escriban /exit.

Mac

Requiere macOS 13 (Ventura) o posterior. Instalen en este orden.

  1. Abran la Terminal. Presionen Cmd + Espacio, escriban Terminal y presionen Enter.
  2. Git y Python. Copien este comando, péguenlo en la Terminal y presionen Enter. Se abre una ventana: den clic en Instalar y esperen a que termine (puede tardar unos minutos). 
    xcode-select --install
    Si responde que ya está instalado, sigan al siguiente paso.
  3. VS Code. Descárguenlo desde code.visualstudio.com, abran el archivo descargado y arrastren VS Code a la carpeta Aplicaciones.
  4. Claude Code. En la Terminal, copien este comando, péguenlo y presionen Enter: 
    curl -fsSL https://claude.ai/install.sh | bash
    No muestra avance mientras descarga; esperen a que la Terminal vuelva a estar lista para escribir.
  5. Inicien sesión. Cierren la Terminal, abran una nueva, escriban claude y presionen Enter. Se abre el navegador: entren con su cuenta de Claude Pro y autoricen. Para salir de Claude Code, escriban /exit.

Comprobar y mandar la captura

Abran una terminal nueva y peguen estos comandos. Cada uno debe responder con un número de versión.

Windows

claude --version
git --version
python --version

Mac

claude --version
git --version
python3 --version

Tomen una captura de pantalla donde se vean las tres respuestas y mándenla antes de la sesión 1. Es el requisito para entrar.
